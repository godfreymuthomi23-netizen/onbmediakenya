# ONB Media

A responsive ONB Media landing page for Original Network Broadcasting.

## Files

- `index.html` - page structure and content
- `styles.css` - visual system, responsive styling, and animations
- `script.js` - scroll reveals and navigation interactions

## Preview

Open `index.html` in a browser. The Watch Videos and Originals controls open the ONB YouTube channel.
